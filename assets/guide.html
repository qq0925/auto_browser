脚本录制模式使用秘籍

点击底栏菜单的 【开始录制】，屏幕左下角将出现红点闪烁的录制状态栏。此时您在网页上的真实点击与表单提交操作都将被实时捕获！

✓ 默认严格完全匹配 (exactMatch: true)
录制点击文字时，系统会自动开启完全匹配，精准绑定当前文字，彻底避免回放时因为模糊匹配（includes）误触长段落或其他包含该关键词的非目标元素。
✓ 多重重名元素智能补全 (多个筛选: N)
当网页存在多个完全同名的按钮（例如列表中有 5 个“删除”按钮）：
  • 点击第 1 个：系统智能记录为 多个筛选: 1，浮窗提示 (第1个/共5个)；
  • 点击第 2 个：系统智能记录为 多个筛选: 2，浮窗提示 (第2个/共5个)；
  • 页面仅有唯一该元素时：参数保持精炼，无额外冗余。
3

核心参数详解：“多个筛选”从 1 到 -1

在“点击文字”、“点击图片”、“输入框提交”以及“数值对比”等核心动作中，「多个筛选」让您可以精准锁定任意位置的目标：

输入值 匹配含义 右侧面板直观展示 典型实战应用场景
1 第 1 个元素 (首项) 点击: 确定 [第1个] 表格首行操作、页面置顶按钮
2, 3, 4... 正向第 N 个元素 点击: 编辑 [第2个] 选中列表指定行的操作项
-1 倒数第 1 个 (末项/最后一个) 点击: 删除 [倒数第1个] 动态加载列表的最新一条数据、翻页尾页
-2 倒数第 2 个元素 点击: 确定 [倒数第2个] 倒数第二项操作、多级尾部导航
0 完全随机抽取 1 项 点击: 点赞 [随机] 模拟真实随机浏览、抽奖、投票模拟

25+ 脚本动作类型完全速查手册

分类 脚本动作名称 核心功能与参数
页面动作 点击文字 在网页中仿真点击匹配的文本。支持出现文字、点击文本、完全匹配、在此之前/之后、多个筛选。
页面动作 点击图片 根据图片 src 关键词定位并点击图片。支持在此之前/之后、多个筛选。
页面动作 滑动页面 模拟用户向上、向下或向指定元素平滑滚动，触发网页下拉懒加载。
数据管理 输入框提交 快速填充指定表单字段，并仿真点击指定的提交按钮。
数据管理 提取文字 提取页面指定元素文本或属性，自动存入跨步骤变量（如 ${orderId}）。
数据管理 设置Cookie / 清除Cookie 一键切换账号身份 Cookie 档案，支持自动刷新页面载入登录态。
脚本控制 跳转脚本 跳转至当前脚本集的任意指定序号（如跳转至第 1 步实现死循环监控）。
脚本控制 控制脚本开关 动态将列表中某些步骤启用、禁用或反相（支持逗号或空格分隔如 1, 3, 5）。
脚本控制 执行本地脚本集 / 脚本替换 将其他已保存的 .json 脚本集作为子函数调用，或完全替换当前脚本。
逻辑判断 逻辑脚本-数值对比 提取页面指定区域数字并与目标值对比（>、<、=、>=、<=），根据结果跳转分支。
逻辑判断 数值对比-点击文字 当提取到的数值满足条件时，立刻自动点击指定文本按钮。
逻辑判断 等待文字出现 轮询等待异步加载的文字（如“支付成功”、“加载完毕”），超时可控。

跨步骤动态变量系统 (${varName})

在整个自动化流程中，后一步骤可以自由引用前置步骤提取的数据。变量语法支持标准 ${varName} 以及简写 $varName：

// 步骤 1：提取网页中的订单号 【提取文字】 -> 选择器: "#order-number" -> 保存至变量: "orderId" // 步骤 2：在后续网址导航或输入框中动态引用 【进入网址】 -> 网址: "https://api.example.com/check?id=${orderId}" // 步骤 3：在通知栏或自定义脚本中消费 【通知栏提醒】 -> 提醒内容: "订单 ${orderId} 已自动审核通过！"

避坑指南与高手进阶技巧

💡

1. 善用执行延迟 (100ms - 500ms)

部分由 Ajax 驱动的网页在点击后需要少量时间渲染弹窗，建议在点击动作后加入 300ms 左右的执行延迟，体验极为平滑稳定。

🔄

2. 动态轮询巧用【跳转脚本】

若需循环等待或监控某个状态，可以在流程末尾放置一个【跳转脚本】，跳转回步骤 1，即可实现自动化无人值守轮询巡检。

⚡

3. 搭配【等待文字出现】防白屏

对于跨页面大跳转，在【进入网址】之后紧跟一个【等待文字出现】，确保目标页面的核心 DOM 加载完成后再继续后续操作。
