# Privacy Policy for Auok Auto Browser

**Effective Date:** February 1, 2026

## 1. Overview
**Auok Auto Browser** (hereinafter referred to as "Auok" or "this Application") is a tool designed to assist users with browser automation tasks. We are committed to protecting your privacy.

This Application operates on a strict "Local-First" principle: **Auok runs entirely offline on your local device (excluding the network activity of the browser being controlled), requires no account registration, and contains no background features that transmit data to our servers.**

## 2. Data Collection and Use

### 2.1 No Account Required
Auok does not require you to register or log in to any account to use its features. We **do not collect, store, or transmit** your username, email address, password, or any personally identifiable information (PII).

### 2.2 No Remote Script Updates
Auok only executes scripts that you import or create locally. We do not operate remote servers to automatically push script updates or modify your local files. You maintain full control over all script files.

### 2.3 Data Processing Location
* **Local Processing:** All automation logic, script configurations, and execution logs are stored solely on your device's local memory or hard drive.
* **Zero Data Transmission:** We do not upload your browsing history, Cookies, script content, screenshots, or any operational records to any external servers.

## 3. Permissions Usage

To provide core automation functionality, Auok requires the following system permissions. We guarantee these permissions are used strictly for local operations:

* **Accessibility / UI Automation:** Used to identify browser window positions, locate web elements, and simulate mouse clicks or keyboard inputs. This is essential for automation tasks.
* **File System Access:** Used solely to read local script files designated by you and to save automation results (such as log files or screenshots) to your selected local folder.

## 4. Network Access
The Auok application itself **does not** engage in any form of "Phone Home" communication.
* *Clarification:* While the **Web Browser** controlled by Auok will access the internet based on your script instructions (e.g., opening specific websites), the Auok software itself does not collect or transmit any of your behavioral data over the network.

## 5. Third-Party Services
Auok is a standalone tool. It **does not contain** any third-party advertising SDKs and **does not integrate** with any third-party data analytics tools.

## 6. Children's Privacy
We do not knowingly collect personal information from users of any age, including children under the age of 13.

## 7. Changes to This Policy
If we decide to change the functionality of this Application in the future (e.g., adding cloud synchronization features), we will update this Privacy Policy, revise the Effective Date, and clearly notify you in the application update notes.

## 8. Contact Us
If you have any questions about this Privacy Policy or the security of Auok, please contact us at:

# Auok自动浏览器 隐私保护政策 (Privacy Policy)

**生效日期：** 2026年2月1日

## 1. 概述 (Overview)
**Auok自动浏览器**（以下简称“Auok”或“本应用”）是一款辅助用户进行浏览器自动化操作的工具。我们非常重视您的隐私安全。

本应用严格遵循“本地优先”原则：**Auok 完全在您的本地设备上离线运行（除被控制的浏览器自身的网络活动外），不需要注册账户，也不包含任何向我们服务器发送数据的后台功能。**

## 2. 数据收集与使用 (Data Collection and Use)

### 2.1 无需账户登录
Auok 不需要您注册或登录任何账户即可使用所有功能。我们**不收集、不存储、不传输**您的用户名、电子邮件、密码或任何个人身份信息。

### 2.2 无远程脚本更新
Auok 仅运行您本地导入或创建的脚本。我们没有设置远程服务器来自动推送脚本更新或修改您的本地文件。所有的脚本文件完全由您掌控。

### 2.3 数据处理位置
* **本地处理：** 所有的自动化逻辑、脚本配置、运行日志均仅存储在您的设备本地内存或硬盘中。
* **零数据回传：** 我们不会将您的浏览历史、Cookies、脚本内容、网页截图或任何操作记录上传至任何外部服务器。

## 3. 权限使用说明 (Permissions)

为了实现核心的自动化功能，Auok 需要请求以下系统权限，我们承诺这些权限仅用于实现本地功能：

* **辅助功能/UI自动化权限：** 用于识别浏览器窗口位置、定位网页元素并模拟鼠标点击或键盘输入。这是实现自动化任务的必要条件。
* **文件系统访问权限：** 仅用于读取您指定的本地脚本文件，以及将自动化运行的结果（如日志文件、截图）保存在您选定的本地文件夹中。

## 4. 网络访问 (Network Access)
Auok 应用本体**不进行**任何形式的“回传（Phone Home）”通信。
* *说明：* 虽然 Auok 控制的**Web浏览器**会根据您的脚本指令访问互联网（例如打开特定网页），但 Auok 软件本身不会收集或通过网络发送您的任何行为数据。

## 5. 第三方服务 (Third-Party Services)
Auok 是一个独立的工具，**不包含**任何第三方广告 SDK，也**不集成**任何第三方数据分析（Analytics）工具。

## 6. 儿童隐私 (Children's Privacy)
我们不会有意收集任何年龄段用户的个人信息，包括 13 岁以下儿童的信息。

## 7. 变更通知 (Changes)
如果未来我们决定更改本应用的功能（例如增加云同步功能），我们将更新本隐私策略，修改生效日期，并在应用更新说明中明确告知您。
